# Organizational Context

1. Purpose
The purpose of this document is to identify and evaluate the internal and external factors that may influence CloudCart's Information Security Management System (ISMS). Understanding the organization's context helps ensure that the ISMS aligns with business objectives, supports risk-based decision-making, and addresses relevant security risks.

2. Internal Issues
| Internal Issue                           | Impact on ISMS                                                                                                                                                          |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AWS Cloud Infrastructure**             | CloudCart relies on AWS to host its SaaS platform. Any misconfiguration or outage could affect service availability, customer data protection, and business continuity. |
| **Microsoft 365**                        | Microsoft 365 is used for business communication and document collaboration. Unauthorized access could expose confidential information.                                 |
| **GitHub Repositories**                  | Source code is stored in GitHub. Weak access controls could result in code theft or unauthorized modifications.                                                         |
| **Identity and Access Management (IAM)** | Effective IAM is essential to ensure employees have appropriate access based on their job roles and responsibilities.                                                   |
